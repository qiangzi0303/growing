# 统一 AI 配置与账户用量

管理后台的「AI 模型」统一设置完整 API 地址、模型名称、Key、启停和实时语音音色。「AI 用量」按北京时间日期、账户和用途查询汇总与明细。仅管理员可管理配置或查看全站用量；保存时 Key 留空表示保留，列表只显示掩码。

## 调用方式

- 网页与 APK 云账号登录后，首次经 `/api/ai/config` 获取配置，会话内存缓存并合并并发获取；刷新页面或重新登录重新获取。退出、失效与切换账号后旧上下文失效，不继续复用其凭据。管理员改配置后，已打开页面需刷新。
- 文本、流式对话和实时语音 SDP 由前端直接请求供应商。供应商必须允许网页域名及 Android WebView origin 的 CORS。Key 会到达登录客户端，因此可以被该客户端查看；它不写入前端持久存储。
- 原有试卷识别、题图处理和手写批改仍由既有服务端工作流执行，接入统一配置与服务端计量。未建立对应配置时兼容旧环境配置；显式停用不回退旧配置。
- 旧个人 Key 不上传、不继续读取使用；学习记录、奖励、原稿及已有账户不迁移或清空。旧 APK 需更新后才能采用新调用方式。

## 部署准备

1. 应用 D1 迁移 `cloudflare/migrations/0020_managed_ai.sql`（按原有顺序执行迁移）。
2. 配置 Worker Secret `AI_CONFIG_ENCRYPTION_KEY`：安全随机生成的 32 字节，以 **64 位十六进制字符串**填写。不要提交到源码或打印到日志。已保存的 Key 使用 AES-GCM 加密；此 Secret 应稳定保存，替换后须重新录入所有 Key。
3. 发布 Worker 和同步后的前端资源，再由管理员填写五种用途：`chat`、`realtime`、`vision`、`paperRecognition`、`paperFigure`。
4. 文本与视觉填写完整 `…/chat/completions` URL；实时填写完整 SDP URL，前端按配置追加 `model` 参数。地址使用 HTTPS，不带账号密码、查询参数或 fragment。

## 本地连接云端数据

`cloudflare/wrangler.jsonc` 的 D1 绑定已启用 `remote: true`。项目根目录的 `启动本地测试.bat` 继续启动 `http://127.0.0.1:8790/console/`，启动参数已移除 `--local`，以允许远程 D1 绑定。页面和 Worker 在本机运行，账号、角色及数据库记录来自云端 `growing-db`；本地操作会直接修改云端数据。

切换后使用云端账号重新登录。本地测试数据库保留，不向云端导入测试账号或学习记录。`.dev.vars` 保存与云端一致的加密密钥，已由 Git 忽略；不要更换或提交此密钥。其余资源绑定保持原配置，本次未切换 APK 文件的 KV 存储。

此电脑通过 Windows 系统代理访问远程绑定。启动器会将系统代理传给 Wrangler，并用 `.nmai/tmp/wrangler-remote-proxy.cjs` 为 Wrangler 4.151.3 / Miniflare 5 的内部 `ProxyWorker` 配置出站代理；仅设置 `HTTPS_PROXY` 无法覆盖该内部运行时，会导致 D1 请求超时。升级 Wrangler 后需重新验证此适配。代理凭据和数据库凭据均不写入网页资源。

## 统计口径

客户端将供应商响应中的 usage 上报 `/api/ai/usage`，账户由后台认证确定。每次请求携带唯一 requestId 与配置 revision，重复上报不重复累计；历史配置修改后仍归属原模型。

输入、输出和合计 token 分开显示。缺少或无效 usage 的请求记为「未知」，不会伪装成零消耗。错误、取消也保留状态；统计汇总只累计已知 token，并另列未知请求数。实时语音按生成响应计量，建立连接失败单独记未知失败。

`client` 标明客户端上报，可能因关闭页面、断网或客户端修改而漏报/失真，适合使用情况统计，不能作为可信结算依据。`server` 为既有视觉工作流实际调用的服务端记录。上线前的历史调用无法据此追溯补计。

用量上报采用独立的每账户 120 次/分钟限流，不占用原有模型调用额度；前端上报最多等待 5 秒，失败不丢弃已生成的回答。旧实时语音代理接口返回 410，引导用户刷新网页或升级应用。
