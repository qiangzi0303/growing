## 已实现的范围

- PC 与手机浏览器使用同一个响应式网站，网站根路径为学生/家长云账号入口，登录后按身份显示学习中心或家长看板。
- Cloudflare Workers TypeScript API + D1 SQLite，通过原生 `DB` 绑定访问数据库；同一个 Worker 提供 PC/H5 网页和家长后台。无需 .NET、IIS、Docker 或 Containers。
- 学生/家长分别注册云账号；密码使用 Web Crypto PBKDF2-SHA256（100,000 次、每人随机 16 字节盐）保存哈希。网页使用 Secure/HttpOnly/SameSite=Lax 会话 Cookie；APK 使用独立云令牌，数据库仅保存令牌 SHA256。
- 家长注册后直接进入“我的孩子”，无需立即绑定。顶部“设置”中提供“添加孩子”，可随时返回首页、稍后再绑定。学生生成 10 分钟有效、一次性的 12 位绑定码；家长绑定后可查看多个孩子。学生可查看、解除家长绑定，接口每次查询都校验关系。
- 数学、物理微课的已读、掌握和练习情况；英语普通单元的词条/微课记录与按原有规则计算的掌握项数；按学科查看同步时间和活跃时长。
- PC/H5 课程存档按云用户 ID 在本机隔离。先同步再打开课程；学习中本机持续保存并周期同步，断网时保留记录。
- APK 保留原本机账号、离线课程和存储命名。通过“账号 → 云同步 / 家长关联”把当前本机账号关联到学生云账号，初次需要明确勾选同意。不同本机账号可关联不同云学生；旧密码不上传，也不会自动转换成云账号。
- 同一记录跨设备冲突会要求选择保留本机/云端版本，选择前先在本机备份两个版本。已打开课程期间不自动拉取替换记录，避免内存中的旧状态覆盖新版本。
- API 密钥与云会话不进入云存档；原分式存档中的 `connection` 字段在上传前剔除，拉取时保留当前设备已有连接设置。
- 管理员登录后进入管理中心，查看全站会员总览、按用户名/称呼搜索、身份筛选和分页；学生详情包含三科学习记录、关联家长、成长曲线和核销记录；家长详情包含关联学生与确认记录。
- 管理员顶部提供“管理中心 / 学生课堂 / 家长看板”和“设置”，同一会话直接切换，无需更换账号。学生课堂可打开全部数学、英语、物理课程，试用记录按管理员 ID 单独保存在当前设备；家长看板支持搜索、分页查看全站学生，无需绑定。设置仍可使用绑定码关联孩子。
- 家长对已同步的设备核销记录确认“已实际兑现”，管理员查看全站云端确认账本，按学生或家长筛选。账本保存实际登录家长、设备原称呼、设备时间与确认时间，不接受客户端传入的金额。
- 成长曲线支持近 7/30/90 天、三科学科与掌握/已读/练习/时长切换，并提供每日数据表。同步成功时生成当天快照，同一天保留最后一次快照。

PC 采用浏览器网页。布置任务、后台发放/审批奖励、管理员在线授权、密码找回与推送通知尚未实现。管理员为专用账号，由数据库所有者授权；管理中心提供查询，不包含删除会员或修改学生存档。

## 管理员与核销的使用方式

1. 初始化数据库（见下节）后，在网站注册一个**独立的家长账号**作为管理员专用账号，不与日常家长账号混用。公开注册接口只允许学生或家长，不能自选管理员。
2. 数据库所有者在 Cloudflare 控制台的 D1 → `growing-db` → Console 中执行以下语句，把示例用户名替换为注册时的完整用户名（精确匹配，保留大小写）：

```sql
INSERT INTO "GrowingAdministrators" ("UserId")
SELECT "Id" FROM "GrowingUsers"
WHERE "Username" = '实际管理员用户名' AND "Role" = 'Parent'
ON CONFLICT DO NOTHING;
```

3. 使用此账号重新登录网站根路径，即进入管理中心。选择会员可查看详情；选择学生可查看学习记录、成长曲线和设备核销；从会员详情进入该会员的核销确认账本。
4. 撤销管理员权限时，由数据库所有者执行：

```sql
DELETE FROM "GrowingAdministrators"
WHERE "UserId" = (SELECT "Id" FROM "GrowingUsers"
                  WHERE "Username" = '实际管理员用户名' AND "Role" = 'Parent');
```

每次请求均重新验证权限，已有会话也立即失去管理员接口权限。移除后恢复该账号原家长身份。管理员可访问全部课堂资源和学生看板读接口；普通家长仍需绑定才能查看。课堂试用不会写入学生云存档，核销确认仍由实际家长完成。切换管理员页面时会重新查询身份并清理旧页面请求和监听器，撤权后下一次请求拒绝管理员专属访问。

家长在“我的孩子”中选择学生，查看奖励与核销，核对后点击“确认已实际兑现”。这一步仅记账，不转账、不控制游戏、不重复扣除原课程奖励。每笔记录只能确认一次，重复请求不增加账目；解绑后该家长不能再查看或确认学生记录，管理员仍可查历史。学生修改或删除设备记录后，已生成的确认账本仍保留。

设备端的“妈妈”等称呼只是自填文字，不代表已登录的云端家长；历史设备记录保持此来源标记。旧版只有累计总额的记录仅展示摘要，不伪造核销人。设备累计摘要与云端确认账本属于不同口径，不可相加。

成长快照从部署本功能后学生首次成功同步开始积累。缺少快照的历史日期保持空白，不能从当前掌握数反推；旧记录中的按日时长仍可展示。重学或重置可能导致掌握曲线下降。会员列表“7 天内同步”表示上传记录的学生数，不代表严格的活跃学习人数。

## 首版统计边界

原分式课堂与英语 Unit 3 的存档会同步，家长汇总沿用它们各自的规则：原分式按有效 AI 评分达到 8 分或历史掌握记录计入，英语 Unit 3 按七次正确的单词与达到 80 分的课堂检测记录计入；英语其他单元按必会词条七次正确、微课检测全部正确计算，选学词不计掌握。数学/物理普通微课需概念解释和应用练习均达标。看板展示掌握项数，尚未提供全部课程分母的百分比。

新增活跃时长只在课程前台可见、最近 60 秒有交互时累计，按设备独立记录；旧版离线时长不会凭空补齐。对每一天取原课堂有效时长与新增活跃时长的较大值，保留历史日期并避免同一段重复叠加；这是一种保守汇总，不用于精确计费。多个设备同时学习可能分别计时。各课堂练习存档口径不同（如微课检测记录、近期战绩或累计练习次数），看板统一标为“练习记录”，不代表统一考试次数。所有信息是学生设备的最近同步记录，供家长参考，不是考试防作弊认证。

同一浏览器的多个标签页应避免同时编辑同一课程；跨设备使用时先返回学习中心同步，再在另一台设备打开课程。发现冲突时先关闭课程再处理。浏览器的离线保存不等于完整 PWA 离线包；完全离线学习优先使用 APK。

## Cloudflare Workers 部署

架构：PC/H5/APK → HTTPS Worker（静态页面 + API）→ D1 SQLite。

本机需安装 Node.js 22+ 和 Python 3。在 `growing/cloudflare` 目录执行：

```text
npm ci
npm run assets
npm run check
npm test
npm run bundle
npx wrangler login
npm run db:remote
npm run deploy
```

以上命令更新当前已配置的数据库和 Worker。如部署到其他 Cloudflare 账号，先登录该账号，执行 `npx wrangler d1 create growing-db`，将返回的真实数据库 ID 写入 `wrangler.jsonc` 后再执行远程迁移、发布。D1 使用账号授权和绑定，无需创建数据库密码。

`assets` 从仓库课程及共享页面生成 `cloudflare/public`，同时生成英语统计规则；`deploy` 也会先构建这些资源。该目录不手动编辑、不提交。`npm run bundle` 是本地打包检查，不发布。Web CI 运行编译、测试、打包并保留产物，Worker 源码部署使用上述命令；Android CI 则自动发布 APK 和更新清单，无需重新部署 Worker。

Workers Static Assets 托管网页；所有请求先经过 Worker。`/learn/*` 的课程资源要求学生或管理员会话，普通家长无法直接读取课堂；HTML 注入按云账号隔离的存储桥，管理员使用独立的课堂试用存储。API、登录页及课程响应使用 `no-store`，不要配置 Cache Everything 绕过这些控制。

当前账号为 Workers Free，配置不指定自定义 CPU 上限；该套餐曾以错误 100328 拒绝 `limits.cpu_ms`。本次已在真实免费套餐上验证注册、登录、同步等流程，但这不代表高并发或所有数据规模下的性能保证。登录、注册、邀请码与绑定共用每 IP 每分钟 20 次限流；Cloudflare Rate Limiting API 在各位置分别计数，并非全网严格总计。

截至 2026-10-22，D1 免费额度为每天读取 500 万行、写入 10 万行，单库 500 MB、账号总存储 5 GB。额度按数据库行数计算，不等于 API 请求数；索引维护和三科学习快照也消耗写入额度。D1 与 Workers 分别受各自免费套餐限制，实际以控制台及官方最新定价为准。

网站 `/api/health` 检查服务并标识数据库类型；`/api/ready` 查询必需表，返回 200 才代表数据库绑定和表初始化可用。当前两者均为 200。缺少 `DB` 绑定或必需表时，就绪检查失败。

当前按独立域名根路径部署，不支持 `/某个子目录/`。如使用自己的域名，在 Worker 的 Settings → Domains & Routes 添加并确认 HTTPS；无需另设 Pages 或 .NET 服务器。

D1 原子 `batch` 与学生级版本校验保证学习存档并发更新，失败整批回滚；一次性邀请码使用独立消费标识，防止重复绑定及解绑后复用；核销插入时重新检查家长关系和源记录版本，唯一约束保证重复确认幂等。保留原存储键和同步协议。每学生最多 256 份、合计 16 MB 云存档，每份最多 100 万字符，且 UTF-8 编码不超过 1,900,000 字节（适配 D1 每行 2,000,000 字节限制）；请求体最多 2,200,000 字节。

本地预览先运行 `npm run db:local` 初始化本地数据库，再执行 `npx wrangler dev --local`。本地 D1 与远程 D1 独立。自动化 API 测试使用 Miniflare 临时 D1，不连接正式数据库。

## 手写图片识别与文字评分

图片识别调用登录后的 POST /api/handwriting/ai，只允许学生及管理员。识别时发送全部 PNG 页面，逐页转录并提示不清楚处；用户核对确认后，评分复用已有三科共用的 GrowingCourseAI DeepSeek 连接，仅发送题目和核对文字，不再单独配置手写评分模型。英语第四项评价标点与格式，不根据文字猜测书写美丑。

视觉配置从 NumaAI llm_models 与关联的 AIProvider 提取，保存在 Worker Secret HANDWRITING_VISION_MODELS，格式是按优先级排列的 JSON 数组，每项含 name、model、endpoint、apiKey、customHeaders、additionalConfig。地址严格为保存的 endpoint 追加 /chat/completions。图片使用完整 PNG Data URL。上游异常、限流、空响应、截断或无效转录会尝试下一个已保存模型；全部失败保留原稿，不产生分数。不会向页面返回上游凭据、原始错误或思考内容。

本地使用 Git 忽略的 cloudflare/.dev.vars；JSON 数组使用 dotenv 单引号包裹。不要将密钥写入源码、前端、学习存档、命令参数或 Git。正式发布需单独设置同名 Worker Secret，本地配置不会自动上传。

2026-10-24 核查用户指定的 glm-4.6v-flashx,deepseek-flash：NumaAI 未保存前一个名称；已提取后者的实际配置与密钥，真实 PNG 调用可识别手写数字。未擅自替换为其他 GLM 型号；grsai-banana2 为生成图片配置，本流程不调用。

接口限制为最多 8 页 PNG、每页 1,000,000 字符、总请求 8,100,000 字节，每账号每分钟最多 6 次（Cloudflare 各位置分别计数）。其他学习存档接口保持原大小限制。原稿、确认、知识点评估及同步权限沿用既有逻辑。

## APK 接入

仓库 `platform-site.json` 的 `apiBaseUrl` 已设为 `https://growing-platform.qiangzi0303.workers.dev`。新 APK 使用该地址。也可在构建环境变量或 GitHub Repository Variable 中设置 `GROWING_CLOUD_URL`。旧 APK 的内置配置不会因修改服务器而自动改变，需要覆盖安装新版。

执行 `python scripts/sync-platform.py` 同步共享界面，再按既有固定签名流程打包。已有 APK 需要先覆盖安装含云同步的新版本。在 APK 本机账号中进入云同步中心，注册或登录学生云账号并确认关联；服务器有记录时先处理版本选择，再继续学习。家长用电脑或手机网站登录家长账号查看。

APK 同步服务与 APK 自动更新是两项独立配置：`platform-site.json` 控制云服务，`update-site.json` 控制版本检查；可以使用同一站点的不同路径。未配置云地址时不发网络请求，原离线课程继续可用。
