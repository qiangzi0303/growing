# 英语课程：沿用已确认的单词学习方式

用户已确认将 Unit 1 的方式用于其他英语单元，今后新增英语课程默认采用本技能，无需再次询问是否沿用。当次明确要求优先。新增课程以真实教材或用户提供的范围为准，不能把未核对的下册占位单元补成猜测内容。

## 词卡与呈现

- 同一“单词学习”入口包含完整词表、词卡、正式默写和到期复习。覆盖教材全部单词、短语及选学词，保持原ID、教材词义和选学标记；数据按完整单元ID隔离，不能只按单词名跨单元覆盖。
- 每个词条有与教材词义匹配的插画、简洁中文图注、英文例句、准确译文和常用搭配，提供听发音。音标仅录入可靠来源，不凭OCR猜测。
- 优先复用同词同义的词光（Word Atlas）图；缺图或画面词义不符时使用当前可用的图像生成技能生成并实际检查。不能以不相关的同名图、文字占位或重复通用图冒充完成。英文例句和中文译文也必须匹配教材义。
- 词表颜色依真实掌握记录：已掌握浅绿 `#e4f1e3`、边框 `#a3c69e`，标注“✓ 已掌握”；待掌握浅橙 `#fff3df`、边框 `#e5c698`；选学白底。到期复习不撤销已掌握颜色。
- 保持简洁：不加回“先默写一次”、提示按钮或提示框、页面插画来源文字。素材授权、作者、原始链接和生成来源保存在素材来源文件中。

## 正式默写：七次连续正确

- 展示中文释义，隐藏英文答案和插画。答对后按回车或空格立即进入本词下一次默写，清空输入并保持焦点；不能返回词卡、显示答案反馈卡或要求点“继续”。任一次拼写错误立即清零，重新连续正确七次。
- 短语中间的空格正常分词；输入完整词数且光标在末尾时，空格提交。回车可直接提交；空输入、长按重复事件、输入法组合状态不得意外提交或重复累计。短语不能因缺少分词空格而无法输入。
- 七次完成后按教材词类检查适用的名词复数，再验证词义与词类。七次完成时收起词卡释义及插画，口述验证不泄露完整参考答案。
- 只有有效的口述评分同时通过词义、全部词类且无错误，才写入新的完整掌握记录。取消、超时、无效响应、未保存均不得算成功；复数的接受形式沿用已核对规则。单元原有专名大小写约束须保留。
- 每次提交消费当前草稿一次。草稿、连续次数和阶段可刷新恢复；保存失败保留当前结果并阻止继续，重试保存不得再次计数。兼容旧反馈存档时保留已计次数，清除已提交的草稿与反馈，不再次处理答案。

## 到期复习与成绩

- 复习间隔为 1、3、7、14、30 天，按本地日历日安排；每词同一天最多推进一次。提前答对不推迟到期；答错或回看答案后次日再练，当天订正不升级。逾期一次复习即可，不补做逾期天数。
- 默认先复习必会到期词，再学新词；已达标但没有复习档案的必会词可先检查。选学不强制加入每日任务。
- 每日复习与正式七次验证保持各自流程。每日一次真实独立拼写最多贡献一次练习记录，不绕过复数和口述门槛；旧选择题试学不能冒充独立默写。
- 保留旧 `seven-recalls` 和 `word-mastery-v2` 成绩、奖励、句子闯关、学习时间以及其他课程记录；复习失败不撤销已达标的历史成绩。不得换存档key后让旧成绩消失。
- 存储读改写保留未知字段，处理外部冲突及账号切换，不能覆盖另一个单元或账号的记录。

## 接入和验证

修改前阅读 [项目接入说明](references/project-integration.md)，复用当前组件与控制器。新增英语知识点及应用题同时遵循已有 [course-practice](../course-practice/skill.md) 的十题分层约定；不要为了统一词卡而改写已有课程的题量或成绩。

- 课程必须接入目录、入口、词表、素材和读档链路，不能只生成数据文件。新增册次用完整单元ID查找数据，不复用上册同编号数据。
- 检查每词图像可解码、路径存在、例句及译文正确、图义相符；实际查看图片，尤其同形异义词及短语。
- 运行受影响的控制器、复习、成绩、素材及组件测试与真实构建。用独立存档在桌面、手机浏览器验证连续正确、错误清零、短语空格、第七次切阶段、刷新续写、保存失败重试、掌握颜色及旧成绩兼容。
- 对统一流程变更覆盖所有受影响单元入口；只修改单词内容时按内容影响检查。说明真实AI服务与受控响应各验证了什么，不把模拟评分说成真实在线评分。
- 完成授权范围内的本地资源同步并校验；本技能不额外授权发布、修改真实学习记录或发送消息。
