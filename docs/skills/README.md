# 项目课程技能

这里保存项目课程技能的版本化副本。NumaAI 实际加载的是项目根目录 `.nmai/skills/` 下的技能；本仓库位于该项目的 `growing/` 子目录。

- [英语课程学习](english-course-study/skill.md)：新增英语课程默认沿用完整插画词卡、掌握颜色、连续七次默写及间隔复习。
- [课程分层练习](course-practice/skill.md)：新增知识点配套十题分层练习，维护原稿批改和历史成绩兼容。

恢复时，将这两个技能目录复制到项目根目录 `.nmai/skills/`，再通过该项目的 NumaAI 技能重载接口加载。修改运行中的技能后，同步更新此处副本。
