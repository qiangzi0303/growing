# 课程录入与十题分层练习

用户已确认：后续录入的课程沿用十题分层练习及解答题拍照作答方式。满足触发范围时自动采用，无需再次询问是否沿用；用户当次明确要求优先。只实施当前授权的课程内容，技能不授予发布、改生产数据或调用付费服务的额外权限。

新增或补充英语课程时，同时使用 [英语单词学习规范](../english-course-study/skill.md)，沿用插画词卡、连续七次默写和间隔复习；本技能负责知识点及应用题的分层规则。

## 课程与题目

- 以真实教材、用户资料或已确认的教学范围确定学科、册次、单元、知识点及先修要求；资料不足的教材出处不编造。录入到既有课程结构，沿用讲解、步骤、例题、易错点和复述等已有栏目。
- **每个知识点10题**，不是每章合计10题。顺序固定为第1–6题基础、第7–8题提高、第9题难题、第10题综合应用。第10题采用综合应用已是默认约定，不再把6＋2＋1的差额作为待确认问题。
- 基础题覆盖核心概念和直接应用，提高题增加条件辨析或组合步骤，难题要求适龄推理，综合题联系情境或多个相关方法。难度来自思考层次，不靠超纲知识、模糊条件或单纯增大数字。
- 数学、物理沿用现有默认题型：前8题为选择题，第9、10题为解答题。其他学科按实际教学目标采用合适题型，同时保持十题及难度分布，确保对应输入、校验和计分真正支持该题型。
- 每题具备稳定ID、完整题干、必要题图、答案及可核验解析；选择题选项唯一且只有一个正确答案。既有题目合并后也须去重，不能把同一题换序当新增题。
- 解答包含必要步骤、单位与适用条件；独立核算数值，验证几何条件确实可实现。题目需要图时提供已核对图形，不能用缺图题设或按示意图测量代替条件。

## 解答题拍照与手写

- 每道解答题提供“拍照 / 手写解答”，复用项目现有原稿工作台和视觉批改，不另造上传与批改链路。手机支持拍摄或选图，电脑支持上传和画布书写。
- 以学科、单元、知识点和题目ID定位题目；题干、原稿和批改须属于同一道题。固定题目模式锁定题干与题目选择，返回原知识点的应用练习，保留选择题草稿。原稿ID更新时保留题目上下文。
- 原始照片、笔迹与批改结果分别保留；恢复、继续作答或重试沿用正确原稿。实际发送该原稿页给视觉模型，不能拿题干、旧反馈或参考答案冒充学生作答。
- 未作答、模糊、待复核、批改失败或原稿已修改时不计通过。失败、取消、超时或存储异常保留当前作答并明确说明未完成保存或批改，不能伪造成功状态。

## 计分与兼容

- 每题通过计1分，满分10分。选择题未选不默认选A；解答题仅接受属于本题当前原稿修订的有效批改，总分及关联知识点评价均须至少80分，`needsReview` 不计通过。
- 应用练习10/10才算本轮通过。沿用课程原有概念复述、掌握和奖励规则，不把答完选择题等同于整组练习通过。
- 十题成绩按真实题量保存；旧三题成绩单独标记并兼容读取，不能把旧3/3直接显示为新10/10。保留已有原稿、成绩历史及奖励，避免重复奖励。
- 切知识点清除上一题组的临时提交状态；保存失败时界面仍使用当前答案显示逐题反馈，明确未保存。同步核对单元总结、学习报告、掌握度和排行榜的题量与达标判断。

## 接入与验收

修改项目课程代码前，按需读 [项目接入说明](references/project-integration.md)，确认当前入口、数据结构与共享模块。新课程也必须完成目录、路由和知识点映射接入，不能只生成题库文件。

- 对新增知识点检查10题、6/2/1/1分布、ID/题干不重复、选项与答案合法、解答任务正确关联，并独立核算易错题。
- 运行受影响的真实测试或编译；浏览器验证电脑和手机的十题展示、草稿恢复、拍照导入与重载、原题返回、批改失败重试、待复核不通过及最终计分。选择与提交状态不能跨知识点串用。
- 仅题库内容变更时运行覆盖新数据的结构检查并抽查受影响题目；共享计分、路由或拍照逻辑变更时补验相应行为，不机械重跑全部无关检查。
- 模拟AI响应的检查只证明流程；交付时明确是否验证过真实服务，以及尚未验证或受阻的内容。发布状态按实际操作说明。
