# 学习评分与排行榜

英语满分100分，仅包含 **单词默写50%＋句子闯关50%**。数学和物理保持费曼学习30%＋应用练习70%。图谱诊断、阅读、语法检测、英语费曼复述、奖励与学习时长不计入英语成绩，历史记录保留。

- 单词项按必会词的有效达标数／必会词总数计算，选学词不计入分母。沿用七次正确默写的历史记录，以及当前单词流程对适用复数和词义词类口述的验证要求；旧Unit 3保留原有拼写兼容规则。
- 句子项按有效整句通关数／本单元总句数计算，同一句反复练习只计一次。后端重新验证题目ID、完整答案和完成记录，不采信客户端总分；游戏内积分不用于成绩计算。
- 两项各固定占50%；未完成部分记0，不把权重转给另一项。全部单词达标得50分，全部句子通关得50分，两项全部完成得100分。
- 学期科目榜分别汇总该学期全部已开放单元的两项分子与分母后加权，不平均单元总分，未开始单元仍计入分母。下册未开放内容不造榜。
- 本地课堂与目录使用共享的 english-score.js；同步后的排行榜、单元报告和活动汇总采用相同有效记录。目录可直接读取句子记录，不依赖旧奖励进度缓存。
- 英语旧排行榜缓存原先保存的费曼／混合检测计数已不适用。读取榜单时检测旧分母并按源存档重建，也补入历史上只有句子通关、尚无榜单行的学生。重建使用同步版本保护，不改学习原稿。
- 同分并列，前20名分页，当前学生名次单独返回。其他学生使用稳定匿名榜名，不返回账号、学生ID或作答文本；家长须绑定孩子，管理员须具有管理权限。
- 重置或删除学习记录会重算当前成绩；原已获得、已核销奖励保留，同一进度不会重复发放。排行榜以最近一次成功云同步为准，离线新记录需先同步。

## 本地验证

- scripts/english-score.test.cjs：固定50/50、满分、未完成、无效记录、选学词、旧Unit 3和当前单词达标门槛。
- scripts/english.test.cjs：普通英语各单元与奖励换算。
- cloudflare/test/rankings.test.ts：8个英语单元与学期分母，以及数学、物理原有规则。
- cloudflare/test/unit-reports.test.ts、reports.test.ts：达标项和报告口径。
- cloudflare/test/api.test.ts：真实本地D1的缓存重算、句子单项补榜、并列排名与权限。

## 部署

本次修改不自动发布。上线时须先按现有环境应用所需数据库迁移，再发布包含同步学习网页资源的Worker。已有榜单可通过管理员重建接口重建；英语旧缓存也会在读取时修正。APK内嵌网页需随应用升级，已安装旧APK不会自动获得新页面代码。不要在命令行或日志中提供管理员令牌。
