# 学习排行榜

学生学习中心显示“我的排行榜”，家长在已绑定孩子的学习报告中查看“孩子的排行榜”。管理员在学生报告中也可查看。其他学生以稳定匿名榜名显示，不返回账号、学生ID、复述文本或作答内容。

总分为 **概念定义掌握率 × 30 + 测试掌握率 × 70**，满分100，按两位小数排名。同分并列，后一名保留名次间隔。前20名分页展示，当前学生名次单独展示，未进第一页仍可看到。

- 概念项：数学、物理为课程目录中的知识点；英语为阅读/语法微课。有效AI概念解释评分≥8/10且无核心错误计为掌握。旧分式保留历史有效概念达标记录；旧英语Unit 3使用其已有5项费曼复述、80/100达标记录。
- 检测项：数学、物理按每个知识点3题应用练习的最好正确比例；旧分式按各知识点普通应用验证的最好正确比例（专项补充不重复加分）；英语按必会词条七次默写及每节3题检测，旧Unit 3按原分组检测的最好正确比例。每个知识点/词条/微课/旧分组是一个检测项。
- 单元榜的分母为该单元全部概念项、检测项；学期科目榜分别汇总该学期全部已开放单元的概念项、检测项后再按30/70加权，不平均各单元总分。未学习部分记0。
- 学期按教材上册/下册划分，尚未引入学年、班级模型。当前均为八年级。未开放的英语、物理下册不造榜。
- 只为有实际阅读、作答、解释或草稿记录的单元参榜；初始化空存档不参榜。重置/删除记录会重新计算当前分数，不保留历史最高名次。只以最近云同步记录计分，离线未同步内容不展示。
- 普通英语单元新增“概念复述”，使用已有DeepSeek连接；草稿与有效评分随该英语单元存档同步，密钥继续只保存在本机。原奖励和课程掌握规则不变。

排行榜基于可离线学习、可同步的存档，不是防作弊监考系统；服务器按已知课程ID与记录格式计算，不采信客户端直接传入的排行榜总分。

## 部署顺序

1. 执行 `wrangler d1 migrations apply growing-db --remote`，新增0003派生分数表。此迁移不删除或修改原学习存档。
2. 执行 `python scripts/sync-platform.py`、`npm run check`、`npm test`、`npm run deploy`。
3. 使用已登录管理员的会话token，仅通过环境变量提供 `GROWING_ADMIN_TOKEN`，执行 `node scripts/rebuild-rankings.mjs https://007yx.com`，为所有已有学生重建索引。不要将token写入仓库、命令行参数或日志。
4. 验证学生/家长榜单。以后每次学习存档同步，索引随源文档在同一CAS事务中更新。重建可重复执行；版本保护防止并发旧快照覆盖新同步。

共享云界面已同步到APK源码；已安装旧版APK需覆盖升级含本功能的新版，才会包含新增入口与普通英语复述界面。网页版部署不要求用户重装APK；旧版仍能同步其已有学习记录。

## 本地验证

`cloudflare/test/rankings.test.ts` 覆盖权重、固定分母、旧课堂、异常记录和学期隔离；`api.test.ts` 使用真实Miniflare D1覆盖同步事务、并列、分页、匿名、学生/家长权限、重置与历史重建。部署前还应执行页面与响应式浏览器检查。
