# 学生学习报告

管理员或家长登录后，点击顶部“学生学习报告”，进入独立后台页面（`/#learning-reports`）。管理员可搜索、分页选择全站学生；家长只能选择已关联的孩子。学生账号不显示入口。

报告按已学习的开放单元展示：学科与册次、留存学习日期、有效学习时长、概念复述评分、题目评测进度、课程达标项数与比例、完整图谱评测结果，以及手写原稿当前版本的最近评分。支持学科与册次筛选、刷新。没有学习记录时显示空状态。

时间取各课堂已保存的单元计时；普通数学/物理按实际课程节点归属汇总，兼容旧分式和英语 Unit 3。普通英语课堂新增单元有效计时，每 10 秒保存，60 秒无操作暂停，隐藏、失焦、设置与等待 AI 不计。旧时间不补算，只有学科总时长时不分摊到单元。学习日期仅来自留存活动与评测时间；云同步时间单独展示。

课程达标按课堂既有要求统计：数学、物理与分式须概念及应用均通过；英语必会词汇须 7 次正确默写，阅读语法须全部题目正确，旧 Unit 3 知识关卡按最好成绩达到 80%。浏览不算达标；图谱初筛与手写评分单独展示。题目评测采用排行榜的既有题项口径，不是统一考试次数，未修改排行榜权重。

只读接口：

- `GET /api/admin/students/:id/unit-report`：仅管理员，检查目标为学生。
- `GET /api/parent/children/:id/unit-report`：仅已关联家长或管理员。解除关联、撤销管理员权限后立即失去访问权限。

接口只返回单元汇总，不返回学习草稿、作答内容或手写笔迹。只能看到已同步到云端的记录；离线未同步部分不会出现。

验证：`cloudflare` 下执行 `npm run check`、`npm test`；项目根执行 `node --test scripts/english.test.cjs scripts/unit-summary.test.cjs scripts/test-platform.cjs`。本次本地真实 Worker 浏览器检查覆盖管理员、家长、学生三种角色、筛选与切换、手机布局、错误重试和英语计时同步；测试日志与截图在项目 `.nmai/tmp/unit-reports-qa*`。
