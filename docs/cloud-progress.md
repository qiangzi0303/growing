# 学习记录保存与换设备恢复

学习记录按学生云账号保存到现有 Cloudflare D1 的 `GrowingDocuments` 表。设备只保留离线缓存和待上传内容；更换设备时使用同一个学生云账号登录，不需要重新注册。

## 保存与恢复

- 学生登录后直接进入课程列表，管理员打开课堂也直接进入课程列表，不再显示进入课堂或重新连接的中间页。已绑定身份的 APK 启动不等待账号复核，读取与保存学习记录在后台进行。
- 课程保存后约 400 毫秒触发上传，学习过程中每 15 秒复核，重新联网时自动补传。同步在后台运行，前端不显示同步中、已同步、未同步、失败或同步时间提示。
- APK 使用云账号校验用户名和密码，新设备不再要求先创建同名本机账号。再次登录会保留已关联旧账号的原存储位置。
- 已关联学生账号的 APK 在网络暂不可用时自动沿用此账号的缓存，联网后继续后台核对。首次登录仍需联网确认身份，不提供本地 / 云端选择。
- 云端是学习记录的权威来源：没有可信基线的本机记录、跨设备同时改动、上传遇到版本更新，均自动采用云端（含删除记录），不弹窗、不要求选择。本次学习基于已知云端版本产生的新作答仍会自动保存。
- 后台恢复涉及当前页面已读取的存档时，静默刷新当前课程并禁止旧页面继续回写过期数据；未涉及当前课程的数据不会触发刷新。密钥等设备配置继续保留，不参与学习记录覆盖。

## 上传范围

数学、英语、物理课程的已读与掌握进度、练习与解释草稿、学习日历与时长、奖励及核销存档、诊断结果、未完成的诊断进度、手写作业、英语答疑与草稿均纳入云存档。拍照题库与错题作答次数原本直接写入服务端，继续沿用。

AI 密钥、设备语音设置、云登录令牌及同步内部元数据不作为学习记录上传。分式存档中的 AI `connection` 配置上传前剔除，恢复时保留当前设备自己的配置。未保存的输入框、尚未提交的网络请求不等于已保存的学习存档。

## 旧记录迁移

旧版未关联学生的浏览器记录保留在原位置，但不再弹出迁移或版本选择页面，也不会自动认领为当前学生的云记录。账号缓存由后台云端数据更新；未建立云端基线的旧本机内容不能覆盖云端。已上传的学习记录继续按账号跨设备恢复；从未上传的数据无法由另一台设备恢复。

新存档键复用既有服务端文档与版本控制，无新增数据库迁移。现有按学生隔离、乐观并发校验及存档容量限制继续适用。

## 验证

`scripts/test-platform.cjs` 覆盖同步决策，`cloudflare/test/api.test.ts` 使用真实临时 D1 验证换会话恢复和权限，`scripts/test-cloud-progress.py` 对隔离的本地 Worker/D1 验证实际课堂保存、新设备恢复、断网补传和原生存储适配。Android 的 `CloudAuthClientTest` 验证云登录协议；`CloudAccountTest` 验证设备缓存和旧账号迁移，已加入覆盖升级 CI 流程。

本轮更改需要发布新版网站和 APK 后才会在正式环境生效；旧 APK 的本机登录流程不会由服务器静态部署自动改变。
