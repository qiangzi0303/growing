# 学习记录保存与换设备恢复

学习记录按学生云账号保存到现有 Cloudflare D1 的 `GrowingDocuments` 表。设备只保留离线缓存和待上传内容；更换设备时使用同一个学生云账号登录，不需要重新注册。

## 保存与恢复

- 网页和 APK 在进入课堂前读取云端存档并恢复。读取失败不会把空白课堂当成已恢复，页面提供重试。
- 课程保存后约 400 毫秒触发上传，学习过程中每 15 秒复核，重新联网时自动补传。只有服务端确认后才显示“已保存到云端”；网络失败显示缓存保留、尚未云端保存。
- APK 使用云账号校验用户名和密码，新设备不再要求先创建同名本机账号。再次登录会保留已关联旧账号的原存储位置。
- 已关联学生账号的 APK 可在网络不可用时明确选择使用已有缓存，联网后补传。新设备首次恢复需要联网。
- 离开课堂返回主页时重新核对云端数据。正在学习的课程不会被后台拉取突然替换；跨设备同时改动同一记录，需返回学习中心选择版本，选择前保留备份。

## 上传范围

数学、英语、物理课程的已读与掌握进度、练习与解释草稿、学习日历与时长、奖励及核销存档、诊断结果、未完成的诊断进度、手写作业、成长测评和原版四象限测评记录、英语答疑与草稿均纳入云存档。拍照题库与错题作答次数原本直接写入服务端，继续沿用。

AI 密钥、设备语音设置、云登录令牌及同步内部元数据不作为学习记录上传。分式存档中的 AI `connection` 配置上传前剔除，恢复时保留当前设备自己的配置。未保存的输入框、尚未提交的网络请求不等于已保存的学习存档。

## 旧记录迁移

1. 在原 APK 上选择“旧本机账号迁移 / 断网使用已有缓存”，用原本机密码登录，再在云账号页面登录或注册学生云账号并关联。原记录保留，随后自动上传。
2. 已关联的 APK、已按云账号隔离的网页缓存，在登录时自动上传。若本地与云端版本不同，选择后才继续。
3. 同一浏览器内，旧版未关联学生的记录会显示“发现旧版本机学习记录”。核对孩子姓名后点击“把旧记录迁入此学生”。系统先备份，两边不同时要求选择版本，不会静默覆盖。已认领的旧记录不会再次提示导入其他学生。
4. 在原设备看到“已保存到云端”后，再在新设备登录。已经卸载、清空且从未上传的数据，服务端无法从其他设备读取。

新存档键复用既有服务端文档与版本控制，无新增数据库迁移。现有按学生隔离、乐观并发校验及存档容量限制继续适用。

## 验证

`scripts/test-platform.cjs` 覆盖同步决策，`cloudflare/test/api.test.ts` 使用真实临时 D1 验证换会话恢复和权限，`scripts/test-cloud-progress.py` 对隔离的本地 Worker/D1 验证实际课堂保存、新设备恢复、断网补传和原生存储适配。Android 的 `CloudAuthClientTest` 验证云登录协议；`CloudAccountTest` 验证设备缓存和旧账号迁移，已加入覆盖升级 CI 流程。

本轮更改需要发布新版网站和 APK 后才会在正式环境生效；旧 APK 的本机登录流程不会由服务器静态部署自动改变。
