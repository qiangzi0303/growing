# 各单元句子闯关

复用已认可的句内进度、逐词输入与整句挑战，不重新设计练习面板。范围为已有已核实教学资料的八上8单元；下册资料未核实，不生成题库或回退到上册同编号。

1. 各现有微课知识点配置10句原创练习，6基础、2提高、1难、1综合。稳定ID以单元、知识点、序号组成；依据 english-lessons.js 和 Unit3 原课堂内容，不冒充教材原文。
2. 数据显式标注句子成分边界；每词具备中文、音标、词性。废除将所有句子解析为 look forward to 的专用算法。保留原Unit2阅读10句与无参数兼容入口。
3. URL采用 unit 与 topic。单元入口显示知识点选择；选定后保留原练习界面。无效参数显示明确提示，不静默换单元。重开及重练只使用当前题组。
4. 普通7课堂和Unit3专用课堂均接入对应单元；返回原课堂。原课程存档和奖励保持独立。
5. 先增加路由、题库完整性及数据隔离测试并确认失败；完成后运行Node规则和原英语回归。浏览器覆盖8单元入口、35题组及完整流程，手机长句与焦点；复核代码、内容与视觉。
6. 仅选择性同步修改文件到 public/learn，校验哈希，不发布、不提交Git、不运行旧 sync-web.py。

题库按单元拆成小模块，复用同一练习引擎；不引入框架、账号服务或自动生成的错误语法解析。
