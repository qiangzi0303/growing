# 拍照试卷逐题视觉整理

用户已确认把“整理试卷”会话中的按需放大、多轮核对和图形重绘接入拍照导入。

## 实施范围

1. 保留现有逐页题号清点；逐题用视觉模型定位整题，客户端按原像素裁剪，原页始终随视觉请求提供。复核找到的题图选框合并回整题框，后续裁剪包含题干上方或异处的题图。
2. OCR 仅生成草稿；独立视觉复核不接收草稿或参考答案，核对完整题面、选项、小问、根式和图形归属。OCR 失败可进入复核，复核失败不可用草稿顶替。
3. 数学含图题生成现有受限矢量格式，浏览器使用同一渲染器生成预览图片，再对照原页和原题裁剪视觉检查；失败保存问题并允许重绘。标签超出边界时仅扩展 viewport，不移动几何点线。英语与物理保留原图。
4. 每阶段单独持久化，已有任务从当前未完成题升级，保留已完成题与历史记录。完成时写入 FigureDrawing，人工确认字段保持未确认。
5. grade 模式在题设复核之后单独读取真实作答，不能把题设或解答写进学生答案。新流程使用独立视觉配置并保持严格 JSON 解析，其他批改入口保持原配置。无答案导入不生成成绩；标准解答沿用独立 AI 解答入口。
6. 两个前端推进器共用附件准备，图片序号与实际来源页码明确区分；不持久化临时裁剪和渲染 base64。
7. 最终图形复核请求中，每来源页裁剪最多100000字符、每幅预览最多180000字符，四页加八幅图最多1840000字符，保留在现有请求大小限制之内；后端检查各页裁剪与当前题框一致。
