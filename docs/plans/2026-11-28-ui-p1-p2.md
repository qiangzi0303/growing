# UI P1/P2 实施计划

用户已批准 `.nmai/tmp/ui-component-assessment/report.md` 中 C1–C11。目标是在现有 Vue/Vant、Naive UI 和页面布局内完成交互增强，保护学习状态。C12 与 CommentPin 不在本次范围。

## A. 学习端选择与切换（C1–C3，课堂 C4）

- 新建可搜索的 Picker 替代组件，兼容 columns/text/value、modelValue 数组、confirm(selectedValues)/cancel；保持已有 Popup 生命周期。搜索、空结果、当前项、长文本、键盘及焦点恢复可用。
- 将知识点/章节/历史等长列表接入；原有小选择列表可继续用原库。数学实验和三角形速度 0.5/1/2 改原位按钮选择。
- 英数物与旧 Unit3 的按钮式标签统一选中/焦点/键盘行为，内容控制器不重挂载。
- 课堂异步提交、追问扩展现有 ActionFeedbackButton，只以新持久化结果确认成功。
- 文件：learning-ui/src 下课堂、知识图谱、实验、HomeSample、Midterm 及对应测试；不改试卷组件、StudentMathResources、StudentPlatform、StudentHandwriting。

## B. 试卷工作台（C4–C8、C10，试卷 C2）

- 保存题面/题图/作答/草稿与追问反馈接真实结果；保持取消/失败与已保存版本区分。
- 处理进度展示已有真实百分比和阶段，读取状态/空结果/错误区别明确。
- 原操作区域内整理低频工具；主提交/重试/取消保持可见。
- 弹层关闭与焦点返回，历史折叠样式和照片缩略图/页码/预览/失败统一。
- 文件：StudentPaperPages、StudentPhotoReview、StudentPaperAI、StudentFigureEditor、StudentCorrectionPad、StudentUploadHistory、StudentPaperInk，必要的 platform-web/student-paper-pages.js 与对应控制器/测试。
- 不变更评分、存储格式、任务执行算法、账号权限。与 A 共享 SearchablePicker 接口。

## C. 后台日期范围（C11）

- AI 用量起止日期使用已有 Naive UI NDatePicker，保留手输与清空；查询继续输出 YYYY-MM-DD，北京时间包含结束日。
- 保持其他筛选字段与分页逻辑。针对日期选择/清空/请求参数运行测试、typecheck 与真实构建。
- 文件：console-web/src/views/ai-usage/index.vue，必要的局部日期 helper 与 tests。

## D. 根代理集成（C4–C10 剩余覆盖）

- StudentMathResources、StudentPlatform、StudentHandwriting 的反馈、筛选清除与读取状态。
- 共享折叠样式与弹层行为仅修必要差异；复用现有 Vant 组件。
- 为独立模块的重要状态变化补行为测试，视觉轻改不写镜像测试。
- 各实现者先保存当前文件基线（已有大量用户未提交改动）；禁止提交/回退/发布。

## 验证与交付

1. 分模块编译和针对性测试，异步失败/取消/旧结果、搜索/切换/清空、草稿与计时刷新是重点。
2. 根代理构建并同步 learning-ui；后台构建单独处理。必要时构建 APK 验证打包。
3. 用真实页面做 390/768/桌面检查；涉及 AI 使用隔离响应，不写真实账户数据。遵循当前项目本机课堂启动入口。
4. 规格与质量分别复核，修复后复查；最后记录 C1–C11 的完成情况和验证边界。
