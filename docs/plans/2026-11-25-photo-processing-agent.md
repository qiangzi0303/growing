# 后台拍照试卷 Agent 首版

用户已确认方案并授权先实现一版。复用 Cloudflare 后台、现有个人试卷/题库/错题与家庭授权；本轮不提交 Git、不操作线上学生数据。

## 行为

- 新上传由后台队列持续推进，APK/网页只上传、轮询、校对；关闭客户端不取消任务。
- GLM-OCR 使用 layout_parsing 接口，以服务端 ZHIPU_API_KEY 鉴权。已保存成功识别的原页不重复请求，原始响应供后续复用。
- 拍照处理 Agent 加载后台技能策略，分阶段运行 OCR、题号规划、原图复核、受限 SVG 生成、服务端渲染与视觉验证、作答判定、原子入库。
- 复用已审核教材目录中的 unitId/practice.nodeId 和批改知识点；不确定归类留待核对。空白/不清楚不进入错题库。
- 新任务绑定上传者与学生，后台运行和写入前复查家庭关系。阶段租约、版本号和幂等键防重复；重试有界，失败保留原图与进度。
- 历史客户端推进任务保留兼容；后台任务禁止客户端传入裁片、题图或阶段结果。

## 实施分工

1. GLM-OCR 服务端适配器与真实协议测试；接口固定，不输出密钥及图片载荷。
2. 服务端 SVG 渲染器，使用现有受限图形渲染规则；真实渲染测试。
3. 后台技能、任务调度/队列与阶段状态机、入库规则和权限/恢复测试。
4. 客户端对后台任务只轮询；失败可重试；保留历史任务路径与测试。
5. 编译、相关回归、本地集成及浏览器检查；明确真实模型验证和部署状态。

## 验收

- 客户端退出后仍可由后台完成；重发队列消息不会复制试卷/评分。
- API/轮询不泄露 OCR 原始内容和凭据；其他家庭无权访问或重试。
- 数学含图题必须通过重绘验证才完成，不能用照片裁剪替代。
- 可信的单元/知识点关联自动可用；错误/部分正确依据个人作答进入对应错题；未作答/待复核不误入。
- 原始 OCR 记录可审计，重试不会重复调用已完成 OCR。

## 实施结果

首版代码、后台 Skill、GLM 适配器、队列恢复、WASM 渲染、题库关联及前端轮询均已完成，本地密钥已配置。已完成隔离数据库回归、真实浏览器检查和真实原稿含图单题闭环；详细证据与上线配置见 [操作与验证说明](../photo-processing-agent.md)。生产服务及 APK 尚未部署/发布。
