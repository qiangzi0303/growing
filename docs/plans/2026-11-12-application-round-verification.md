# 十题应用练习统一作答与评分

已完成本地构建与资源同步，未发布。适用数学、物理共用的十题应用练习页面。

## 交互

- 前八题直接点选 A / B / C / D，未选择时不默认选 A；选择草稿自动保存。
- 删除基础题、提高题、难题等文字，四个难度等级分别使用绿、棕、红、紫色题干。
- 第九、十题只提供拍照或上传照片，上传阶段保存原稿，不调用批改服务。
- 全部十题作答且照片保存成功后，统一提交；两道解答批改完毕后显示整组分数和逐题反馈，每题一分。
- 待复核、关联知识点评价不足 80 分的解答不计通过。失败、取消或迟到结果不能生成有效整组成绩。
- 修改答案会隐藏不再对应当前答案的评分；切换知识点不会带入上一组的选择或提交状态。

## 保存与兼容

- `practiceChoices` 保存选择草稿；`practiceMode: 'round'` 停止将照片上传过程自动换算为旧版照片成绩。
- `practiceRound` 保存统一提交结果，包含版本、题量、提交时间及十道题的答案/原稿修订和通过状态。成绩模块优先读取该字段，并拒绝损坏的结果回退为旧版满分。
- 原有 `practicePhoto`、`practice10`、三题成绩和照片、批改记录保留。新版结果同时用于掌握度、单元总结、学习报告和排行榜。
- 成绩保存失败时保留本次反馈，重试保存不重复请求 AI 或累计练习轮数。
