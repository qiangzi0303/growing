# 数学与物理目标番茄实施

已获用户授权实施：番茄按单元内容生成数量；每轮有明确目标与前面内容复习；学习始终发生在原课堂；同时适用于现有数学和物理章节。

状态：本地实现、构建和验证完成，详见[验证记录](2026-11-27-course-pomodoro-validation.md)。未远程部署或发布新 APK。

## 实现约定

- 用教材节点、步骤、先修边和十题难度生成确定性计划，不调用 AI 猜测学习内容。每轮预计不超过 25 分钟，预留复习；难题与综合题拆分。完整覆盖每节点十题，末尾综合复习。预计数量与实际计时次数分别显示。
- `course-pomodoro-plan.js` UMD `GrowingCoursePomodoroPlan.build(chapter,subject,questionsForNode)` 返回计划数组。计划 `{id,title,goal,minutes,tasks}`；任务 `{id,kind:'review'|'learn'|'recall'|'practice',nodeId,title,goal,tab,questionIds,minutes}`。首轮通过现有节点要点做入门回忆检查，后续复习前面已安排内容；不虚构单元外先修课程或已学记录。
- round 保留 `planId`，原纯计时历史不改写。任务通过已保存真实事件验证，计时到点不冒充任务完成。每轮复习必须本轮重新完成。未完成任务在后续巩固轮继续，过关才推进计划；历史成绩不清零。
- 控制器 snapshot.pomodoro 增加 `plans`（带 done/total/status）、`selectedPlanId`、`selectedPlan`、`activePlanId`；snapshot.lessonTask 为当前课堂任务。actions `pomodoroSelectPlan(id)`、`pomodoroGoTask(id)`、`pomodoroStart()`、`pomodoroReviewDone()`。选择计划/任务只改变课堂内容，不自动计时。开始后默认进入首个未完成任务。手动回看其他知识点仍可用。
- UI 横排番茄展示全部预计任务，点击进入课堂；目标及复习/讲练任务条在课堂，详情仅记录及计时控制。题目仍来自原课堂，筛选指定题但保留原序号、十题成绩与提交逻辑。
- 两科各用原账号课程存档保存计时状态；损坏、失败、迟到批改与旧历史兼容。
- 未开始计划在原复习知识点内优先已有错题，已有有效掌握证据可以略过重复讲解；开始时冻结复习题号及略过项。基础计划数量与追加巩固轮数分别显示，原十题覆盖不减少。
- 启动、恢复和失败重试均顺序暂停另一学科正在运行的计时；暂停保存失败则拒绝新计时。该检查不构成多标签/多设备原子锁。
- 到时等待休息期间可以完成当前步骤，成果仍属于本轮，但计时不超过 25 分钟。休息后新学习不会倒灌本轮；异步已发起批改仍回原轮。
