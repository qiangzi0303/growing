# 英语单元番茄目标计划

用户最新确认：目标明细只在番茄弹窗展示；每个番茄组合单词、语法、句子闯关、阅读理解。默认10个新词，并复习前面内容；全部学习在原课堂，番茄仅安排目标、定位、计时和查看结果。

- 全部教材单词、短语统一必学，词表运行时 `optional:false`；教材星标仅保存在 `textbookOptional` 来源字段。页面移除必学/选学筛选与样式区别，正式默写、成绩、每日复习和番茄计划均包含原选学词，原ID与成绩不变。
- 基于当前真实 Unit1–8 内容及掌握记录生成稳定计划。新词每组最多10个；语法、句子、阅读按总轮数均衡分配，每轮最多2个新语法知识点（每点仍10题）、8个新句子、1个新阅读目标。允许相邻句子主题同轮，各目标仍定位原主题。总轮数为 `max(ceil(新词/10), ceil(语法/2), ceil(句子/8), 阅读数)`，全部待学内容恰好覆盖一次。
- 某类新内容学完后，从该类已掌握内容及前面轮次选择复习，保证有真实内容的类别继续参与每轮。只补缺失类别；类别复习较少时最多额外加入1个词复习，不再每轮自动填满4项。纯复习轮最多4项；本轮新学与复习不重复。
- 使用原 course key 的 pomodoro 扩展字段 plan 保存计划，新布局为 `mixed-v2`。旧未开始及**正在学习**的计划重新分配；当前轮保留ID、计时、暂停、草稿和所有完成事件，已完成目标优先保留在当前轮，其他待学内容重新组合。保留历史已完成、超时、手动结束和休息中轮次；历史未掌握内容重新进入待学安排。旧无目标8词轮保持兼容。旧计划保存在 `previousPlan`，当前原目标保存在 `previousTargets`；保存失败保留原存档并支持重试，重开后不重复迁移。
- planned round 保存 planId/title/kind/targets，target 包含稳定id、eventId、kind/title、review、新词标识以及课堂定位字段。完成必须由原学习流程真实成功保存产生的事件满足，旧成绩不自动冒充本轮复习。
- 学习25分钟且全部目标完成后进入5分钟休息；累计学习最长50分钟，未完成则自动结束，标记 `endReason: timeout` 并显示紫灰色坏番茄。暂停时间不计入学习时长，暂停5分钟自动续计。旧20分钟已完成或休息中的记录继续兼容；正在学习的轮次沿用原计时，按25分钟标准继续。旧未结束超时记录按新上限封存，已学内容保留，原超长时长存入 `previousElapsedMs`；历史已结束记录不重写。
- 每个待学习番茄均可在弹窗单独开始，不受轮次顺序限制；同一时间只计时一个，已有轮次须先结束。弹窗提供“结束本轮”，使用 `endReason: manual` 保留已学内容及草稿，未完成目标不计完成。手动结束或超时后，继续作答不会自动开启下一轮，须再次明确开始。
- 页面只保留番茄条。正常完成的番茄显示笑脸，手动结束不算成功笑脸，超时继续显示紫灰色坏番茄。点击任意轮先预览弹窗，在弹窗内开始本轮或点击目标定位原词卡/每日复习、语法要点、阅读检测、句子闯关；目标按四类分组并标注新学/复习。已结束轮次只读。课堂对应的本轮未完成节点显示番茄动画，结束后移除；计时刷新不清空课堂答案。
- 句子复习须记录新的完成时间，同时保留旧首次完成成绩。语法复习须真实重新答题；不能只翻阅旧满分答案。错误仍保留原复习订正机制。
