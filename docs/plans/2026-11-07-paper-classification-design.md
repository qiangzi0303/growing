# 拍照试卷考试类型与单元自动归档设计

日期：2026-11-07  
状态：用户于 2026-11-07 确认；已实现并通过本地验证，未提交或发布。

## 目标与范围

家长为已绑定孩子拍照或从相册上传试卷后，自动识别整卷是期中考试、期末考试还是单元测试；单元测试自动关联实际课程单元。覆盖项目现有数学、英语、物理三科，使用共享流程，后续学科接入沿用同一分类契约。

现有整卷上传只接受数学和英语，物理虽已有五个课程单元，仍需补齐入口、存储约束及识别规则。不能以仅修改提示词代替完整支持。当前输入沿用照片/图片及多页上传，不在本需求中新增 PDF 或 Word 解析。

## 方案比较

| 方案 | 做法 | 取舍 |
| --- | --- | --- |
| A：视觉识别并校验真实目录（推荐） | 一次整卷识别同时返回考试类型、归类证据与候选单元，服务端校验，核对页允许修改 | 兼顾无标题试卷和实际归档，复用现有调用，无须额外一次模型请求 |
| B：只按标题关键词 | 读取“期中”“期末”“第几单元”等文字后套规则 | 简单，但无卷头、教材编号不同及标题矛盾时容易误归类 |
| C：家长每次手动选择 | 上传前选择考试类型和单元 | 明确但增加操作，不能满足自动识别目标 |

采用 A，人工修改作为低置信与识别错误时的补救。

## 识别与自动关联规则

1. 在所有科目的共享试卷导入链路识别整卷类型，优先读取卷头、标题、册次及单元名称，再结合题目覆盖内容判断。只有题目覆盖前半册不能直接认定为期中考试。
2. 类型包含 `midterm`（期中）、`final`（期末）、`unit`（单元测试）、`other`（其他）和 `unknown`（待核对），避免把练习卷、月考和模糊照片强行塞入三类。
3. 识别返回类型置信度、依据、候选单元及单元置信度。服务端只接受目录内且同学科、同册次的真实单元；不能仅凭“第三单元”跨教材硬套序号。模型置信度仅作为门槛，仍须结合证据与目录校验。
4. 单元测试有明确证据且达到置信度门槛 0.8 时自动关联；单元不明确则保留“单元测试／单元待核对”。类型不明确则“类型待核对”。标题与内容冲突时提示核对，不静默确定。
5. 明确覆盖多个单元的单元合卷关联多个真实单元；不确定覆盖范围时留待核对，不强制归入一个单元。
6. 期中、期末保留整卷考试类型，不人为指定整卷所属单元；已有逐题单元识别继续独立保存。整卷单元不能覆盖题目原有真实归类。
7. 学科沿用上传入口上下文；识别证据与所选学科冲突时提示重新核对学科，不静默放入错误目录。没有真实单元目录的内容不生成虚构单元。

## 保存与页面行为

- 上传完成的草稿直接显示自动识别结果，例如“英语 · 单元测试 · Unit 3 To be a good learner”。分类与单元在服务端保存，重新打开仍能读取。
- 家长在现有核对区修改考试类型和适用单元，再沿用“核对完成，保存试卷”。选择其他类型时清除整卷单元关联，服务端同步校验类型与单元组合。
- 列表和详情显示考试类型、单元名称及待核对状态；以既有页面为基础添加必要信息，不另建复杂分类后台。
- 保持亲子共用同一份试卷记录、孩子切换隔离、解绑失权和服务端权限复核。上传失败保留已选照片，分类缺失不能伪装成成功归档。
- 草稿自动识别与人工确认有明确区分，保存分类置信度、依据及确认状态，人工修改后不得继续展示成 AI 自动确定的结果。

## 代码与数据改动边界

- `cloudflare/src/question-bank.ts`：扩展共享识别返回值、目录校验、幂等返回、保存、列表、详情及确认接口；覆盖整卷拍照与相关共享上传入口。
- 现有物理提示不能继续默认走数学识别及几何规则；补齐物理题面、单位、公式、必要题图的转录规则，保持原稿与批改职责分离。
- 新增前向兼容迁移，扩展学科约束并增加整卷分类数据；不直接改写旧迁移。SQLite 约束变更须保留原表记录、索引和所有子表关联，使用迁移回归测试验证。
- 旧试卷读为待分类，保留已有逐题单元、原卷、作答及批改历史，不自动批量重识别旧卷。
- `platform-web/my-papers.js` 及课程入口：三科共用上传、核对、列表和详情；物理接入同一试卷入口与返回逻辑。
- 同步 Android 内嵌 Web 副本、缓存版本及 Worker 静态资源；不运行会覆盖新 Web 源码的旧同步脚本。
- 本地交付不包含线上部署、生产迁移、Git 提交或 APK 发布。

## 验收

- 先写分类校验与接口失败用例，再实现；运行 Worker 类型检查、相关后端和前端测试。
- 覆盖三科的期中、期末、单单元、多单元、无卷头、低置信、标题内容冲突、错误学科、目录外单元及册次冲突。
- 验证人工纠正、确认保存、重开读取、上传重试与幂等、旧卷兼容、迁移保留全部记录、家长孩子共享和越权拒绝。
- 浏览器检查家长拍照/相册入口、自动展示、待核对、手动修改、保存和列表回显；检查桌面及手机。
- 当前没有用户提供的真实试卷。模拟视觉返回仅验证流程；真实照片分类和匹配效果另行如实报告，不能用模拟测试声称识别准确率已验证。
