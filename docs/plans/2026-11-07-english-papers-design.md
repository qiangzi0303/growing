# 英语试卷与拍照整理设计

日期：2026-11-07  
状态：方案 A 已实现并通过本地验证，尚未发布；页面直接复用数学“我的试卷”的现有样式，整理规则使用 minimal-learning-ui。  
需求：英语部分像数学一样，增加试卷入口和拍照整理试卷功能。

## 使用方式

1. 英语目录增加“试卷”入口，与数学目录的试卷入口位置一致。
2. 打开后显示“我的英语试卷”和“拍照整理试卷”；英语课堂也能进入自己的试卷列表，保留返回原单元的能力，包括原有 Unit 3 课堂。
3. 学生拍照或从相册按页上传，AI 整理题面，生成待核对草稿；对照原卷修改后保存。
4. 保存后可重新打开、查看原卷、查看无答案净卷和打印，沿用数学现有操作与简洁样式。
5. 家长选择已关联孩子后上传；孩子和家长访问同一份试卷，管理员按学生查看。访问权继续由后端校验。

## 方案比较

| 方案 | 实施方式 | 取舍 |
| --- | --- | --- |
| A，共享试卷系统（推荐） | 共用数学的上传、核对、原卷、保存与权限模块；新增英语学科参数及专用识别规则 | 操作一致，维护集中；需要完整检查共享模块的数学兼容性 |
| B，独立英语系统 | 单独建立英语上传、存储、识别和查看流程 | 英语结构自由度高；重复实现权限、原稿、历史和错误处理，维护成本较高 |

采用方案 A。英语入口仅列出英语试卷，数学入口保持数学试卷；后台按学生查看时保留学科信息。先前效果图只用于展示入口，实际功能沿用数学现有页面，不另建其示例列表布局。

## 英语题面与识别

- 忠实保留原题的英文、中文要求、大小写、标点、选项、空格、题号、小问及材料，不在转录时纠正原题或学生的拼写。
- 完形填空和阅读理解保留共享材料，并将对应小题与材料绑定；跨页材料不能丢失，分区重号不能串题。
- 保留翻译、词汇、语法、书面表达的实际要求。听力部分只整理照片上存在的材料和题目，缺少的音频或听力文本明确留待补充。
- 净卷排除学生答案和教师批注，原始照片及真实笔迹独立保留。识别不清处标记待核对，不猜测答案或错因。
- 识别使用英语教材中已核对的真实单元；无法确认的题允许暂不归类，但整份试卷仍明确属于英语。
- 英语请求不携带数学几何模型，不强制生成几何 SVG；照片中的必要插图保留来源和定位。
- 多页、文件大小和整卷题量做显式校验；超限返回明确错误，不能只保存前半份。依据英语的材料组与小题结构处理整卷，不通过省略题目满足上限。

## 共享模块与数据

- `catalog.js` 及英语资源页负责目录入口；英语课堂、旧 Unit 3 和 `course-navigation.js` 负责课堂入口和返回。
- `platform-web/my-papers.js` 将固定“数学”文案改为学科上下文，列表、上传和打开试卷始终带上同一学科。
- `platform-web/app.js` 与现有兼容导航传递英语上下文；保留当前学生与返回位置，避免切账号或切孩子后出现旧试卷。
- 后端 `question-bank.ts` 和路由接收、校验并返回试卷学科；持久化到试卷记录，列表按学科过滤。
- 数据库兼容迁移将既有未标学科记录按旧数学行为读取；新英语记录明确写入英语，不能因某题单元未确定而混入数学。
- 去重和请求幂等包含学科语义；旧数学请求继续兼容。题面、照片、草稿、历史作答和批改记录保持原关联。
- 复用原卷及逐题工作台，识别、批改提示和知识点关联按英语学科处理，沿用已有原稿隔离、取消、重试和待复核规则。
- 英语手写订正与追问只发送本次作答和独立题设插图；坐标裁图先保存为独立 `FigureImage`，不把含旧答案的整页当作新作答。缺少必要插图时明确拒绝评分，保留原稿。
- 英文题面、批改和追问按普通文字显示，保留美元符号、填空横线和换行；必要插图缺失时仍能打开其他题，但不打印缺图净卷。
- 同步 Android 内嵌资源及 Web 构建资源，更新受影响页面的缓存版本。

## 出错与权限

- 上传、识别、保存失败显示实际错误，保留当前照片或已保存草稿，支持重试；不显示虚假的成功记录。
- 后端继续验证学生身份、家庭关联和管理员权限；学科筛选不能代替访问授权。
- 修改题面后，旧批改继续保留为历史并按版本判断有效性。

## 验收

- 按 superpowers 用例先行：学科隔离、旧数学兼容、英语归类、材料与小题对应、去重和家庭访问权限先有失败用例，再实现。
- 运行受影响的 Worker TypeScript 检查及后端测试；对导航和页面运行相应现有测试。
- 在隔离账号与本地数据库中验证：英语目录进入、拍照/相册、多页顺序、识别草稿、修改确认、重开、原卷、净卷打印、返回原课堂。
- 验证家长与孩子共享同一份记录、其他孩子无权访问、数学入口不混入英语试卷。
- 桌面、390px、320px 检查；模拟 AI 响应只证明流程，真实照片识别是否验证单独报告。
