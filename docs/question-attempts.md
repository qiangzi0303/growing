# 错题作答与错误次数

已接入本项目的数学单元错题资料（1025141010.pdf 的 53 条原稿记录）和学生的拍照题库。

## 学生使用

1. 登录学生云账号，打开“本单元错题”或“拍照题库”。
2. 点击“开始本次练习”，独立完成题目并核对答案后，选择“本次做错”或“本次做对”。
3. 保存后显示累计错误次数、正确次数、总作答次数和最近记录时间；再次练习须点击“再练一次”。
4. 累计做错至少 2 次的题目显示“反复错题”，可勾选“只看做错 2 次及以上”。每道题可分页查看作答历史，每页 20 条。

本功能记录人工核对的结果，不对试题自动判分。拍照与导入题面使用可编辑文字和标准数学公式；转换题面不改变题目 ID 或计次历史。单纯浏览、取消练习、导入试卷不增加错误次数，也不猜测旧试卷实际做错过几次。之后做对会增加正确次数，历史错误次数仍保留。

数学资料在登录后的学习课堂中使用云端计次。直接打开本地网页而没有学生云身份时，可以浏览题目，页面提示登录后记录；联网失败时明确提示，当前待保存结果保留供重试。

## 后台与家长

管理员的学生详情、绑定家长的学生学习看板新增“反复错题（做错 ≥2 次）”。同时汇总数学单元资料和拍照题库，按累计错误次数排序，并可查看各题最近 20 次作答时间和结果。拍照题库还支持按单元筛选反复错题和分页查看全部历史。

## 记录规则

- 按学生、题目来源和稳定题目 ID 分别统计；题号相同不等于同一道题。
- 修改拍照题目的题号、文本或单元会保留原题 ID 和计次历史。
- 每次明确开始的新练习分配独立作答 ID；重复点击、网络重试使用同一个 ID。服务端唯一键保证同一次作答只记一次。
- 待提交的作答 ID 和结果按学生保存在当前标签页的 sessionStorage，页面刷新后继续重试，避免“服务端已保存但回执丢失”导致重复累加。
- 记录时间由服务端生成，学生作答页按北京时间显示。历史独立于课程进度，重置课程不会删除这些作答记录。
- 学生只能读写自己的记录；家长须保持绑定关系；管理员按学生访问。未授权或已解除绑定时拒绝访问。
- 计次不改变原有的掌握比例或奖励。
