# 手写解题与作文

数学、物理、英语课堂顶部提供手写入口，旧分式课堂与英语 Unit 3 也已接入。数学、物理显示“手写解答题”，英语显示“手写作文”，标题、作答提示、识别核对提示及批改规则随学科切换。

本地题库 `handwriting-tasks.js` 覆盖已核对的24个单元，每单元2题，共48道原创练习：数学11章22道解答题，物理5章10道解答题，英语上册8单元16道作文。题目依据当前课程主题编写，不冒充教材原题。英语下册目录尚未核对，物理下册尚未开放，因此不编造相应题目。

首次进入会填入本单元第一题；在“选择题目”中选另一题，再点击“用所选题目新建作业”。选题本身不会替换当前题目或笔迹，新建后旧作业仍保留在“我的手写作业”中。也可选择“自拟题目 / 老师布置的作业”。既有作业继续读取保存时的题目和原稿，不会被题库更新覆盖。

## 使用流程

1. 选择本单元题目，或填写老师布置的完整题目、条件和作答要求；作文需包含主题、体裁和字数。数学强调画图、列式、证明与推导，物理强调实验分析、公式、单位与解释，英语强调单元主题、语言结构和写作要点。
2. 用手写笔或鼠标书写。支持压感、多页、橡皮、撤销和重做；默认忽略手指，可主动开启手指书写。
3. 在图片 AI 设置中填写支持图片的 HTTPS Chat Completions 完整地址、模型名和自己的 API Key。现有 DeepSeek 文字接口不支持此流程。
4. 识别所有原稿，在核对框中逐页修正符号、分数、上下标和单位，勾选确认，再发起批改。
5. 数学和物理按审题20、思路30、推导计算及单位30、表达20分评阅；英语作文按内容25、结构20、语言35、书写清晰度20分评阅。均为100分制。AI 是辅助点评，需要结合教师意见判断。

原图与核对文字会直接发送到所配置的服务，该服务需要允许浏览器跨域请求。未配置时仍可书写和保存。图片 API 配置仅保存在当前账号所在设备，不进入云同步文档。没有使用 NumaAI 内部模型凭据。

## 原稿与有效性

- 原稿以矢量笔迹保存，可重现书写坐标、线宽、压感与擦除，不持久保存图片 Base64。单份最多8页、18000个采样点、900000个JSON字符；超过限制应新建下一份作业。
- 自动保存、立即保存和恢复沿用当前学生账号的本机存储。写入失败时保留页面笔迹，并阻止切换作业，待恢复存储后重试。无法读取的原存档不会被静默覆盖。
- 修改题目、笔迹、核对文字或重新识别后，原确认失效，旧成绩显示为历史点评；取消、网络失败、格式异常不新增成绩。模型无法可靠识别时须返回需要复核且无分数。
- 手写点评独立保存，**不写入概念掌握率、测试掌握率、排行榜或奖励**，避免任意自填题目影响既定费曼30%/题目40%/图谱诊断30%的口径。
- 登录云账号后，原稿沿用版本同步和冲突处理。绑定家长可在学习情况底部查看已同步原稿及点评，解绑后无法继续读取。服务端使用相同的原稿结构验证器，并拒绝原稿内的额外字段。

## 验证边界

浏览器自动化使用受控图片模型响应，覆盖图片传输、确认门槛、分项验算、异常、保存与授权。真实模型的数学识别和作文评分效果尚未验证；需配置真实视觉模型并用学生原稿实测。浏览器使用真实 Chromium Pointer Events 验证压感，尚未测试实体手写笔或 Apple Pencil。本功能随网站及固定签名 APK 发布，不包含拍照或图片导入；已安装旧版 APK 需覆盖升级后才能使用新增入口。
