# 单元总结

数学、物理、英语已开放的24个单元提供统一的简洁总结。入口位于单元目录、课堂顶部与数学/物理图谱页，地址为 `app-design/unit-summary.html?subject=math&unit=math-8a-01`。支持切换学科、学期与单元；未核对教材的下册不生成虚构总结。

页面显示薄弱、不稳、未测、待复测、已通过的数量。点击数字筛选，点击节点直接打开对应微课、词条或阅读语法课。默认显示前12个节点，较长清单可按需展开。旧分式课堂与英语 Unit 3 支持同样的精确跳转；经由 `study.html` 打开也会传递节点参数。没有分享图、导出和复杂路径图。

数学、物理优先显示最近诊断的直接作答结果：两题均错为薄弱，通过一题为不稳，两题通过标记初筛通过；只答一题列待复测。其他节点参考有效历史诊断和课堂证据，阅读、自查和奖励额度不构成掌握证据。课程达标仍要求有效概念解释及应用验证均通过，诊断通过不冒充课程达标。

英语普通单元按原有标准核验词汇7次闭卷默写、阅读语法3/3检测；有效概念复述可提供补学线索。Unit 3沿用7次默写与知识关卡80%的标准，并展示已保存的失败或未完成默写。旧普通英语课堂只保存成功的默写与检测轮次，不能从没有记录反推薄弱，页面明确保留这一限制。

总结只读当前账号设备上的已保存记录，不创建或覆盖存档。跨设备需先完成现有云同步；记录损坏会显示提示，不删除原数据。状态反映已有证据，不是能力认证，也不改变奖励和排行榜规则。

`scripts/unit-summary.test.cjs` 检查24单元覆盖、状态证据、近期失败覆盖历史最好成绩、损坏存档处理及英语旧版兼容。测试已接入网站、Android 和一键发布检查。Unit 3索引由 `scripts/export-english-rules.cjs` 从原课堂数据生成，避免维护第二份词表。
