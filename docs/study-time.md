# 各科学习时间

后台入口：管理中心 → 注册会员 → 学生详情 → 各科学习时间。已绑定家长的孩子看板使用相同统计。

数学、英语、物理分别显示“今日有效学习时间”和“累计有效学习时间”，按时、分、秒显示。今日按北京时间（Asia/Shanghai）00:00 划分；累计是所有已记录日期的时间之和，不受成长曲线的7/30/90天筛选影响。

计时沿用课程已有的按日计时和各设备前台活跃记录，同一科目同一天取两者较大值，避免课程与网页重复计时。各设备的活跃记录先合并；前台活跃计时在页面隐藏或超过60秒无操作时暂停。服务器忽略无效日期、未来日期、负数和非数字时长，每科每天最多24小时。

成功同步时，在同一个 D1 事务中写入 `GrowingStudyTime` 每日记录；重复同步不会重复增加，课程重置或同步删除原记录后，已留存的时长仍保留。首次重置前也会留存旧课程中的已有时间。旧设备历史在下一次学习记录同步时留存，此前报表仍会读取现存记录。系统不会补算从未记录或未同步的学习时间。

上线须先应用新增迁移 `0008_study_time.sql`，再部署服务端与网页。网页和APK活跃计时的日期已统一使用北京时间；APK网页资源通过 `scripts/sync-platform.py` 同步。

验证覆盖：北京时间零点切换、历史累计、无效时长过滤、课程与活跃记录去重、重复同步、课程重置和删除后的历史留存、学生隔离、管理员与家长口径一致，以及桌面/手机后台页面展示。
