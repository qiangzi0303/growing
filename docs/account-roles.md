# 登录身份确认

网站与 APK 云同步中心使用相同的云账号身份。登录及恢复已有会话时，以后台返回的 `roleSelectionRequired` 为准；未确认的普通账号必须选择“学生”或“家长”，保存成功后才能进入业务页面。管理员无需确认。

## 历史账号

旧版注册默认选中学生，数据库只有 `Role`，没有记录用户是否主动确认过。迁移 `0005_role_confirmation.sql` 添加 `RoleConfirmed`，已有普通账号默认未确认，因此上线后需要确认一次。原账号 ID、密码、会话、学习记录和家庭绑定均保留，不重新注册、不清空学习数据。

新版注册使用空的身份选项，必须主动选择；注册成功时将 `Role` 和 `RoleConfirmed=1` 一起写入数据库。

## 后台接口

- 登录和 `GET /api/auth/me` 返回 `role` 与 `roleSelectionRequired`。
- `POST /api/auth/role` 接收 `{ "role": "Student" }` 或 `{ "role": "Parent" }`，只更新当前登录账号，不接受其他用户 ID，也不能设置管理员。
- 角色和确认标记原子写入；重复保存相同身份可重试，已确认后保存不同身份返回 409，避免不同设备覆盖选择。
- 未确认账号可以查询自身资料、选择身份或退出，其余需要登录的业务请求返回 403。公开首页和下载仍可使用。
- 失败时保留选择页面并提示重试；后台保存成功后，刷新、下次登录及其他设备登录都读取已保存的身份。

## APK 主注册入口与本机账号

1.0.10 只修改了网站和 APK 的云同步页面，遗漏了 APK 启动时的原生本机注册入口，因此该版本在主注册页不会要求选择身份。这是入口接线遗漏，不是后台保存后又丢失。

修复后，原生注册页提供未默认选中的“我是学生 / 我是家长”，并要求同意联网注册。选择和注册资料通过仅在内存中读取一次的桥接交给共享云注册页，调用 `/api/auth/register`，将身份写入后台。密码不写入页面存储；旧本机账号的密码不会自动发送到云端。

本机账号已创建、但云端注册失败时，该账号仍处于待确认状态：保留注册页上的选择并可重试，不能进入课堂或家长页面。若云用户名已存在，可在此切换到云登录；不能覆盖已有账号。退出或重启后，可重新登录本机账号，再完成云账号关联。

旧本机账号登录、恢复本机登录状态时，如果没有成功确认的身份缓存，先打开云账号确认页；已有关联会话的账号读取后台 `/api/auth/me`，其他账号须明确登录或注册云账号。后台需要补选时，保存成功后才更新本机身份缓存。返回选科或直接跳转课堂不能绕过；家长确认后进入家长看板。已完成确认的学生仍可离线学习。

无云会话时立即显示关联入口，不先等待网络请求。恢复会话时先显示身份确认说明；所有云 API 请求（包括读取正文）最多等待 12 秒，超时或断网提供重新连接、改用云登录入口。切换登录后，迟到的会话响应不能覆盖登录表单。APK 云页面顶部始终显示返回：未确认及非学生账号返回本机登录并保留记录，已确认学生返回离线主页。系统返回键使用相同规则。`platform-site.json` 与正式构建使用 `https://007yx.com`，旧 Worker 域名保留兼容旧版。

学生云账号仅在身份确认后关联本机记录，并继续校验已有学生绑定，防止换成其他学生后串档。家长可在云同步中心进入家长看板，不关联或上传当前本机学生的学习记录。

APK 原有本机账号 ID、密码哈希和按账号隔离的学习记录继续保留。同一个本机账号确认关联后，不能在云同步页换成另一个云账号或身份；应退出本机账号后切换。家长不会上传本机学生学习记录。

验证包括身份规则 JUnit 测试、共享页面在浏览器中的原生桥接模拟、后台真实 D1 接口测试，以及正式版代码、Android 仪器测试代码编译和 Lint。`NativeRoleTest` 覆盖真实原生注册页、旧账号拦截、保存失败、家长路由与重启；由 CI 模拟器执行。本地没有执行这些 Android 仪器测试，实体设备尚未验证。

## 家长添加孩子

学生端只提供课程、排行榜与云同步，不显示关联家长入口、绑定码或已关联家长列表，也不请求相关列表接口。APK 原生学生账号页的入口名称为「云同步」，家长账号页为「我的孩子」。

家长在「我的孩子 → 添加孩子」或「设置」中填写孩子的学生账号和密码，验证后添加，可依次添加多个孩子。`POST /api/parent/children/account` 接收 `studentUsername` 和 `studentPassword`，只允许添加已确认学生身份的普通账号，并使用现有认证限流。错误密码、未确认身份、家长或管理员账号不会建立关联。

该操作只建立家长与孩子的关系，不创建或切换孩子会话；重复添加同一个孩子不会重复记录。表单提交后清空密码字段，密码不写入浏览器存储或家庭关系表。原有关系继续保留，无需重新添加，也不需要数据库迁移。旧绑定码接口暂保留，兼容已安装的旧版 APK；新版学生页面不再使用它。

## 发布

使用项目现有“一键提交发布.bat”，先应用新增 D1 迁移，再部署 Worker 和共享页面，随后构建 APK。旧 APK 云页面可能无法显示新的确认步骤，用户可先在网站登录确认身份，或更新 APK。未确认前，后台会拒绝其业务同步请求。
